# Ingame-GM-Tickets

Andora soll ein eigenes Ingame-Ticketsystem besitzen.

---

## Zweck

Direkte Hilfe bei Problemen im Spiel.

---

## V1-Grundfunktion

Spieler erstellt Ticket
→ Ticket erscheint für GM/Support
→ GM kann Ticket bearbeiten
→ GM kann Spieler kontaktieren bzw. notwendige erlaubte GM-Aktion ausführen
→ Ticket wird abgeschlossen

---

## Automatischer Kontext

Der Server kann automatisch hilfreichen Kontext an das Ticket anhängen,
z.B.:
- Account
- Charakter
- Realm
- Zone
- Position
- Zeitpunkt
- Onlinezustand
- relevante kontextbezogene Daten, soweit für die Ticketart erforderlich

---

## Datensparsamkeit

Nicht pauschal sämtliche verfügbaren Serverdaten an jedes Ticket hängen.

---

## Trennende Falltypen

GM-Hilfe-Tickets und Spielerreports/Moderationsfälle sind unterschiedliche
Falltypen, auch wenn sie später teilweise dieselbe Supportoberfläche
verwenden können.

---

## V1-Beschränkungen

Keine Enterprise-Funktionen für V1 erfinden:
- keine komplexen SLA-Systeme
- keine unnötigen Supportstatistiken
- keine umfangreiche automatische Ticketverteilung

V1 soll einfach und funktional bleiben.
